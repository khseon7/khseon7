# 👋 About Me

### 기술적 근거를 바탕으로 시스템의 안정성을 집요하게 추적하는 엔지니어 김학선입니다.

단순한 기능 구현을 넘어, 인프라 설계부터 런타임 최적화까지 시스템 전반의 유기적인 흐름을 이해하고 개선하는 데 집중합니다. 특히 보안이 강조된 격리 환경에서 **LLM 인프라**를 구축하고, 장애 발생 시 **JVM 런타임과 OS 레벨**까지 파고들어 근본 원인을 규명하는 과정을 즐깁니다.

---

## 🛠️ Focus & Experience

#### **보안 중심의 LLM 및 RAG 인프라 구축**
외부 네트워크가 차단된 에어갭(Air-gapped) 환경에서 **Amazon Bedrock 기반의 독립형 추론 시스템**을 구현했습니다. VPC Endpoint와 리소스 격리 설계를 통해 데이터 보안과 실시간 파이프라인의 성능 균형을 잡는 아키텍처를 지향합니다.

#### **런타임 분석 기반의 시스템 최적화**
장애 발생 시 단순 재시작에 의존하지 않고 **JVM Heap Dump 및 GC 로그를 정밀 분석**합니다. JNI 호출로 인한 GCLocker 활성화 등 난해한 병목 지점을 데이터로 규명하여, 배치 시스템 장애 발생률 0%를 유지하는 안정적인 운영 능력을 갖추고 있습니다.

#### **인프라 자동화 및 운영 효율화**
환경 의존성 문제를 해결하기 위해 **CI/CD 파이프라인과 Standalone 패키징**을 적극 활용합니다. 동료들이 인프라 제약 없이 본질적인 개발에만 집중할 수 있는 환경을 만드는 것에서 엔지니어로서의 보람을 찾습니다.
